CSS

Layout and styling patterns worth keeping within arm’s reach.

flexbox-center.css css 
/* perfectly center any child */
.container {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}

The one-liner every developer eventually memorizes. Works on any container; swap min-height for a fixed height if the parent isn't full-viewport.

grid-areas.css css 
.layout {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar content"
    "footer footer";
  grid-template-columns: 220px 1fr;
}
.header  { grid-area: header;  }
.sidebar { grid-area: sidebar; }
.content { grid-area: content; }
.footer  { grid-area: footer;  }

Named template areas read like ASCII art of the page itself — the fastest way to reason about a layout without counting grid lines.

custom-properties.css css 
/* define once, reuse everywhere */
:root {
  --brand: #F2A65A;
  --gap: 1.5rem;
}
.button {
  background: var(--brand);
  padding: var(--gap);
}

Custom properties cascade and can be overridden per-component or per-media-query, unlike Sass variables which are compiled away.
