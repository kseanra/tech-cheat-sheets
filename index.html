flexbox-center.css css 
/* perfectly center any child */
.container {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}

The one-liner every developer eventually memorizes. Works on any container; swap min-height for a fixed height if the parent isn't full-viewport.

array-methods.js js 
const nums = [1, 2, 3, 4, 5];

nums.map(n => n * 2);        // [2,4,6,8,10]
nums.filter(n => n % 2 === 0); // [2,4]
nums.reduce((a, b) => a + b);    // 15

Chain them: nums.filter(n => n % 2).map(n => n * n) reads left-to-right as "keep odds, then square."

safe-access.js js 
// optional chaining — stops instead of throwing
const city = user?.address?.city;

// nullish coalescing — fallback only for null/undefined
const name = user.name ?? 'Anonymous';

Unlike ||, ?? won't replace 0, '', or false — only null/undefined.

fetch-async.js js 
async function getUser(id) {
  try {
    const res = await fetch(`/api/users/${id}`);
    if (!res.ok) throw new Error(res.status);
    return await res.json();
  } catch (err) {
    console.error('Fetch failed:', err);
  }
}

Always check res.ok — fetch only rejects on network failure, not on 4xx/5xx responses.

f-strings.py python 
name, score = "Ada", 97.436

print(f"{name} scored {score:.1f}%")   # Ada scored 97.4%
print(f"{name!r} → {score=}")          # 'Ada' → score=97.436

The = specifier (3.8+) prints the expression and its value together — handy for quick debugging without a separate print.

context-manager.py python 
with open("data.txt") as f:
    lines = f.readlines()
# file is closed automatically here, even on error

Use with for anything that needs cleanup — files, locks, DB connections. It guarantees teardown even if the block raises.

gpg-github-setup.sh cli 
# 1. generate a key (choose RSA/ed25519, then a name + email + passphrase)
gpg --full-generate-key

# 2. find the key ID (the part after the algorithm, e.g. "3AA5C34371567BD2")
gpg --list-secret-keys --keyid-format=long

# 3. export the public key in the armored format GitHub expects
gpg --armor --export <KEY_ID>

# 4. GitHub → Settings → SSH and GPG keys → New GPG key → paste the exported block

# 5. tell git to sign every commit with that key
git config --global user.signingkey <KEY_ID>
git config --global commit.gpgsign true

# one-off signed commit, if global gpgsign is off
git commit -S -m "message"

The email on the GPG key (gpg --list-secret-keys) must match a verified email on your GitHub account, or commits show up as unverified. Push and check for the "Verified" badge on GitHub to confirm it worked. See multi-account-gpg.sh below for juggling more than one key.

multi-account-gpg.sh cli 
# ~/.ssh/config — one Host alias per GitHub account
Host github.com-work
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519_work

Host github.com-personal
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519_personal

# clone/push using the alias instead of "github.com"
git remote set-url origin git@github.com-work:org/repo.git

# ~/.gitconfig — route identity + signing key by folder
[includeIf "gitdir:~/work/"]
  path = ~/.gitconfig-work
[includeIf "gitdir:~/personal/"]
  path = ~/.gitconfig-personal

# ~/.gitconfig-work
[user]
  email = me@company.com
  signingkey = AAAA1111
[commit]
  gpgsign = true

# confirm which key actually signed a commit
git log --show-signature -1

includeIf gitdir swaps user.email and signingkey automatically based on which folder a repo lives in, while the SSH Host alias picks the matching key on push/pull — no manual switching, no global config to remember to change back.
