How this JSON formatter works

      
Paste any JSON object or array into the input box above. Format pretty-prints it with your chosen indent; Minify strips all whitespace down to the smallest valid representation. If the JSON is malformed, the error banner reports the line and column where parsing failed, so you don't have to scan the whole payload by eye.
