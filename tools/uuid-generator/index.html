About version-4 UUIDs

      
A v4 UUID is a 128-bit identifier built almost entirely from random bits (122 of them), formatted as xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx. The 4 marks the version, and the leading digit of the next group is constrained so the value is recognizable as a UUID. With that much randomness, collisions are astronomically unlikely — safe to use as primary keys, request IDs, or idempotency keys.
