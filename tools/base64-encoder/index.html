About Base64 encoding

      
Base64 turns arbitrary bytes into a string using only 64 printable ASCII characters (A–Z, a–z, 0–9, +, /, with = as padding). It's commonly used to embed binary-ish data — images, tokens, credentials — inside text formats like JSON, URLs, or HTTP headers that can't safely carry raw bytes.
