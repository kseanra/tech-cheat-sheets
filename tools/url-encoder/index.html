URL Encoder

Component vs. full-URI encoding

      
Encode component (encodeURIComponent) escapes everything that isn't safe in a single query parameter or path segment — including /, ?, & and =. Use it when encoding one value that will be inserted into a URL.

      
Encode full URI (encodeURI) assumes the input is already a complete URL and leaves reserved characters like :, /, ? and & alone, only escaping spaces and other unsafe characters.

      
Need to go the other way? Use the URL Decoder, or hit Swap above.
