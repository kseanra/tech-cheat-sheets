What is a Unix timestamp?

      
A Unix (epoch) timestamp counts seconds — or milliseconds, depending on the system — since 00:00:00 UTC on 1 January 1970. Databases, logs, and APIs frequently store time this way because it's a single unambiguous number with no timezone to misinterpret; use this page to move between that number and a date you can actually read.
